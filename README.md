# Заявка на гарантийное письмо СОГАЗ по ДМС

Страница собирает заявку АО «ЦППГГ» в ООО «Газпром Персонал» (услуга 16 по Каталогу) в один PDF:
лист заявки с вашими ФИО, должностью, датой, текстом и подписью, а после него приложения (PDF или фото).

## Где хранятся данные

Только в браузере на устройстве, где открыта страница (localStorage). Страница ничего не отправляет
на сервер: PDF собирается на устройстве, сторонние адреса запрещены политикой безопасности страницы
(Content-Security-Policy, `connect-src 'self'`). Приложения не сохраняются вовсе. Кнопка
«Удалить мои данные» стирает все сохраненное, флажок «Не запоминать на этом устройстве» отключает
сохранение совсем (для чужих и общих устройств).

Для работы без интернета `sw.js` хранит копию файлов самой страницы. Данных из формы в этой копии нет.

## Что умеет

- Свернутый раздел «Как пользоваться страницей» с шагами и подсказками.
- Подсказывает родительный падеж, если ФИО или должность введены в именительном («Исправить»).
- Дата ставится сегодняшняя и обновляется сама; если выбрана другая, страница об этом напоминает.
- Кнопки частых формулировок над полем текста и список недавних текстов.
- Отметка на каждом листе приложения: «Приложение к заявке от ДД.ММ.ГГГГ, лист N из M» (с учетом поворота страниц).
- Имя файла с фамилией: `Заявка_ДМС_Петровой_21.10.2026.pdf`, тема письма с кнопкой «Копировать».
- Если PDF больше 8 МБ, кнопка «Уменьшить размер» пересохраняет фото и сканы с меньшим разрешением.

## Как поменять реквизиты

Номер и дату договора, код и название услуги, адрес почты, тему письма и кнопки частых формулировок
страница берет из `config.json`. Его можно править прямо на GitHub (карандаш «Edit this file»):
меняйте только текст в кавычках. Название договора пишется в творительном падеже, как после слов
«в соответствии с». В `phrases` знак `|` отмечает, где окажется курсор после нажатия кнопки.
Если `config.json` не загрузится, страница возьмет значения, записанные в `index.html`.

## Обновление файлов

`index.html`, `config.json` и шаблон (`assets/base.pdf`, `assets/serif.ttf`) браузеры перечитывают
при каждом открытии страницы с интернетом. Если меняете библиотеки (`vendor/`), шрифты интерфейса (`fonts/`)
или значки, увеличьте `VERSION` в `sw.js`, иначе у тех, кто уже открывал страницу, останется старая копия.

## Состав

- `index.html` — страница целиком (разметка, стили, код).
- `config.json` — реквизиты договора и услуги, адрес и тема письма, частые формулировки.
- `sw.js` — копия файлов страницы для работы без интернета.
- `assets/base.pdf` — шапка бланка, `assets/serif.ttf` — шрифт для текста заявки (Liberation Serif, подмножество).
- `vendor/` — pdf-lib, @pdf-lib/fontkit, pdf.js, petrovich (сборки без изменений), `vendor/standard_fonts/` —
  значковые шрифты pdf.js для галочек в бланках, `fonts/` — Golos Text и PT Serif.

Лицензии сторонних файлов перечислены в `THIRD_PARTY.md`.
